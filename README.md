# MEDIROVA — MediConnect Healthcare Platform

> On-demand medical services — connecting patients with verified healthcare providers.

See [`mediconnect/README.md`](mediconnect/README.md) for the full documentation.

**Live repo:** https://github.com/Iswaro/MEDIROVA

## Quick Start

```bash
cd mediconnect/backend  &&  npm install  &&  npm run dev
cd mediconnect/frontend &&  npm install  &&  npm run dev
```

Frontend → http://localhost:3000  
Backend API → http://localhost:5000/api/v1
